# Проверка недели

Правило: у каждой открытой сделки есть следующий шаг — дело с датой в будущем.

CRM недоступна — «CRM не подключена для этого аккаунта» и стоп.

## Шаги

1. Если запрос из Telegram — короткий `reply`: «Проверяю открытые сделки…».
2. `crm_leads(owner="me", status="open", limit=50)`; пока не охвачен `total` — следующие страницы через `offset`.
3. По полю «ближайшее дело» каждой строки:
   - дело с датой сегодня или позже — ✅ в порядке;
   - дата в прошлом — ⏰ шаг просрочен;
   - дела нет — 🧭 без шага;
   - отметка «протух» — 🥀 (дополнительно к статусу).
4. Сводка.

## Формат сводки

Простой текст, без Markdown; рамка ``` — только для наглядности.

```
🗓 Проверка недели · 23 открытые сделки
✅ С шагом: 15
⏰ Шаг просрочен: 5
🧭 Без шага: 3
🥀 Протухли: 4

⏰ Просрочено
• «Клиент · суть» — звонок от 21.10 · стадия «Переговоры»
🧭 Без шага
• «Клиент · суть» — стадия «Подбор»

Начнём ставить шаги? Пойдём по 5.
```

Больше 10 строк в списке — первые 10 и «…и ещё N».

## Пачка из 5

1. Возьми следующие 5 сделок: сначала просроченные, потом без шага; внутри — по сумме, крупные первыми.
2. По каждой открой `crm_lead(lead_id)` и посмотри последние дела и заметки, чтобы шаг был по делу.
3. Предложи шаг: тип (звонок или встреча), дата и время в рабочие дни этой или следующей недели, короткая формулировка.
4. Просроченное дело: спроси, сделано ли.
   - Сделано — предпросмотр `crm_activity_done(activity_id, result)` с итогом со слов человека, затем новый шаг.
   - Не сделано — новый шаг; старое дело человек закроет или перенесёт в CRM сам.
5. Вызови `crm_activity_add(lead_id=…, type="call" | "meeting", title=…, schedule_from="ГГГГ-ММ-ДД ЧЧ:ММ")` — только предпросмотры.
6. Покажи пачку:
   ```
   📝 Пачка 1 из 2
   1. «Клиент · суть» — звонок 28.10 11:00: узнать решение по лоту 12
   2. …
   Ответьте «да» — все, «да 1, 4» — выборочно, или поправьте дату и текст.
   ```
7. После «да» — `crm_confirm` по одному на каждый подтверждённый `preview_id`. Итог: «✅ Записано: 1, 2, 4. ⚠️ 3 — не записано: причина».
8. «Следующие 5?» — и так до конца списка или до «хватит».

## Не делай

- Не ставь шаги без «да» и не подтверждай пачку целиком, если человек выбрал часть.
- Не меняй стадии и поля сделок в этом навыке. Видишь, что сделка явно умерла, — предложи отдельно: «Перевести в «проиграно»?» (`crm_lead_move` → «да» → `crm_confirm`).
