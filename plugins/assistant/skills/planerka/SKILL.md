# Планёрка

Интерактивный план дня. Только чтение, пока человек не скажет «да» на следующие шаги.

## Шаги

1. Если запрос пришёл из Telegram — сразу короткий `reply`: «Собираю день: календарь, CRM, почта…».
2. Дата и часовой пояс — из `ts` сообщения и настроек календаря. «Сегодня» и «вчера» считай в поясе человека.
3. Календарь (Calendar-коннектор, только чтение): события сегодня — время, название, место или ссылка на встречу. Отменённые не показывай.
4. CRM — если инструменты есть и отвечают. Самые дешёвые вызовы, без `crm_lead` на каждую сделку:
   - `crm_leads(owner="me", status="open", limit=50)`; если `total` больше 50 — следующая страница через `offset`.
   - По полю «ближайшее дело» каждой строки: дата сегодня → в «📅 Сегодня»; дата в прошлом → «⏰ Просрочено»; дела нет → «🧭 Без шага». Отметку «протух» покажи рядом с названием (🥀).
   - Закрытия ближайших 14 дней: `crm_leads(owner="me", status="open", sort="expected_close", limit=20)`. Если в строках не видно даты закрытия — открой `crm_lead` только у первых 5 и возьми `expected_close_date`. В «🔥 Толкаем» — сделки с закрытием от сегодня до +14 дней.
   - Новые заявки: `crm_inbox_list(pending_only=true, limit=20)`. Ошибка доступа — раздел пропусти молча.
   - CRM недоступна — одна строка «CRM не подключена — план по календарю и почте» и дальше без CRM-разделов.
5. Почта (Gmail-коннектор, только чтение): письма во входящих со вчерашнего утра — непрочитанные или ждущие ответа от клиентов, партнёров, застройщиков. Рассылки, промо и уведомления пропусти. Итог — 3–5 строк.
6. 🎯 Три главных дела: выбери по деньгам и срокам — просроченное по крупным сделкам, закрытия на этой неделе, встречи, требующие подготовки, письма с дедлайном. Каждое — конкретное действие.

## Формат ответа

Простой текст, без Markdown; рамка ``` у шаблонов — только для наглядности, в Telegram её нет. Раздел длиннее 8 строк — первые 8 и «…и ещё N». Пустой раздел — «— нет» или пропусти. Больше ~3500 символов — раздели на два сообщения.

```
📅 Сегодня
• 10:00 Показ виллы · Клиент · Чангу
• Дело CRM: звонок · «Клиент · суть»

⏰ Просрочено
• «Клиент · суть» — звонок от 24.10

🧭 Без шага
• «Клиент · суть» — стадия «Переговоры»

🔥 Толкаем (закрытие ≤ 14 дней)
• «Клиент · суть» — 250 000 $ · до 05.11 · «Договор»

📥 Новые заявки
• 3 неразобранные: Проект · канал

✉️ Почта
• Отправитель — суть — что нужно сделать

🎯 Три главных дела
1. …
2. …
3. …

Поставить следующие шаги в CRM?
```

Суммы, даты и стадии — только из ответов инструментов. Чего нет в данных — не пиши.

## Если человек ответил «да» на следующие шаги

1. Возьми сделки из «⏰ Просрочено» и «🧭 Без шага», по 5 за раз.
2. Для каждой предложи шаг: тип (звонок или встреча), дата и время в рабочие часы, короткая формулировка. Если по строке непонятно, что делать, — открой `crm_lead` и посмотри последние дела.
3. Просроченное дело: спроси, сделано ли оно. Сделано — предпросмотр `crm_activity_done` с итогом и новый шаг. Не сделано — новый шаг; старое дело человек закроет или перенесёт сам.
4. Вызови `crm_activity_add(lead_id=…, type="call" | "meeting", title=…, schedule_from="ГГГГ-ММ-ДД ЧЧ:ММ")` для каждой — это только предпросмотры.
5. Покажи списком с номерами:
   ```
   📝 Предлагаю поставить:
   1. «Клиент · суть» — звонок 29.10 11:00: уточнить решение
   2. …
   Ответьте «да» — все, «да 1, 3» — выборочно, или поправьте.
   ```
6. После «да» — `crm_confirm` по одному на каждый подтверждённый `preview_id`. Итог: «✅ Записано: 1, 2. ⚠️ 3 — не записано: причина». Затем: «Следующие 5?».
