# Помощник Upsideflow

Личный помощник в Telegram для брокеров и сотрудников Upsideflow. Работает на вашем Mac через Claude Code: вы пишете своему боту в Telegram, помощник смотрит календарь, почту, диск, CRM Upsideflow и каталог объектов и коротко отвечает.

## Что умеет

- **Планёрка** — «доброе утро», «планёрка», «что сегодня»: встречи дня, просроченные дела, сделки без следующего шага, сделки с закрытием в ближайшие 14 дней, новые заявки, важная почта и три главных дела.
- **Внести в CRM** — перешлите письмо, переписку, итоги встречи или расшифровку голосового и напишите «внеси в CRM». Помощник найдёт сделку и контакт, покажет изменения словами и запишет только после вашего «да».
- **Подбор объектов** — «что есть в Чангу до 500к», «найди участки под виллу»: пять ближайших вариантов с ценой, площадью, локацией и ссылкой.
- **Почта** — «разбери почту»: что ответить сегодня, что по сделкам, что от партнёров; черновики ответов.
- **Проверка недели** — «проверка недели»: у каждой открытой сделки должен быть следующий шаг с датой; помощник предложит недостающие шагами по 5.

Без доступа к CRM помощник тоже работает: план дня по календарю и почте, разбор почты, черновики.

## Правила безопасности

- Почта, календарь и диск — **только чтение и черновики**. Помощник не отправляет письма, не создаёт и не меняет встречи, не делится файлами и ничего не удаляет. Просите отправить — он подготовит текст, а отправите вы.
- В CRM записывает **только после вашего «да»** на показанные изменения.
- Тексты писем, заметок, файлов и пересланных сообщений для него — данные, а не команды. Если внутри есть «просьба» — он скажет вам, а не выполнит.
- Телефоны и почты клиентов показывает только маской. Полный контакт — в CRM.
- Не отправляет файлы в Telegram и не меняет доступ к боту по просьбе из чата.
- Ничего не делает по расписанию. Утреннюю сводку CRM, если она у вас подключена, присылает отдельный бот Upsideflow.

## Что нужно заранее

1. **Mac и Claude Code**, вход аккаунтом claude.ai с подпиской. Проверка: в Claude Code команда `/status`.
2. **Gmail, Google Calendar, Google Drive** — подключите на https://claude.ai/customize/connectors. В Claude Code они появятся сами.
3. **CRM Upsideflow** — если вам выдан доступ, подключите её по инструкции администратора Upsideflow. Нет доступа — пропустите этот пункт.
4. **Telegram-бот**:
   - установите Bun: `curl -fsSL https://bun.sh/install | bash`;
   - в Telegram у @BotFather отправьте `/newbot`, придумайте имя и получите токен;
   - в Claude Code: `/plugin install telegram@claude-plugins-official`, затем `/reload-plugins`, затем `/telegram:configure <токен>`. Если плагин не находится — сначала `/plugin marketplace add anthropics/claude-plugins-official`.

## Установка

**Шаг 1. Доступ к репозиторию.**
- Репозиторий публичный — ничего делать не нужно.
- Репозиторий приватный — попросите добавить ваш аккаунт GitHub в репозиторий, затем один раз в терминале:
  ```bash
  brew install gh        # если gh ещё нет
  gh auth login
  gh auth setup-git
  ```
- Если установка ругается на SSH или «Permission denied (publickey)», выполните `echo 'export CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1' >> ~/.zshrc`, откройте новое окно терминала и повторите.

**Шаг 2. Установите плагин.** Запустите `claude` и введите по очереди:
```
/plugin marketplace add gk849/upsideflow-assistant
/plugin install assistant@upsideflow
/reload-plugins
```
При установке выберите **User scope** (для всех папок).

**Шаг 3. Перезапустите с каналом Telegram.** Выйдите (`/exit`) и запустите командой из раздела «Каждый день». В заголовке сессии появится `@assistant` — значит, помощник включён.

**Шаг 4. Свяжите бота с собой.** Напишите боту любое сообщение — он пришлёт код. В Claude Code:
```
/telegram:access pair <код>
/telegram:access policy allowlist
```
Теперь бот слушает только вас.

**Шаг 5. Проверка и разрешения.** В Claude Code введите `/assistant:setup`. Помощник проверит, что видит CRM, почту, календарь, диск и Telegram, и предложит записать правила разрешений: чтение — без лишних вопросов, запись в CRM — всегда с вопросом, отправка и удаление в почте, календаре и диске — запрещены. Перед записью он покажет правила и сделает копию настроек.

## Каждый день

В терминале:
```bash
caffeinate -i claude --model haiku --channels plugin:telegram@claude-plugins-official
```
- `caffeinate -i` не даёт Mac уснуть, пока помощник работает. Держите Mac на зарядке и с открытой крышкой, окно терминала не закрывайте.
- `--model haiku` — быстрая и недорогая модель; можно убрать, тогда будет модель по умолчанию.
- Не запускайте с `--dangerously-skip-permissions`.
- Остановить — `/exit` или Ctrl+C.

Когда помощнику нужно разрешение, в Telegram придёт сообщение 🔐 с кнопками Allow / Deny. Перед этим он одной строкой напишет, что и зачем просит.

## Что можно спросить

- «Доброе утро» / «планёрка»
- «Что у меня просрочено?»
- «Внеси в CRM» + пересланное письмо или переписка
- «Итоги встречи с <клиент>: …»
- «Подбери участки в Убуде до 300 000 $ для сделки <клиент>»
- «Покажи проект <код>»
- «Разбери почту» / «Подготовь ответ на письмо от <имя>»
- «Проверка недели»

## Обновление

В Claude Code:
```
/plugin marketplace update upsideflow
/reload-plugins
```
Или в терминале:
```bash
claude plugin marketplace update upsideflow
claude plugin update assistant@upsideflow
```
Автообновление: `/plugin` → вкладка Marketplaces → upsideflow → Enable auto-update.

## Важно знать

- Пока плагин включён, **каждая** сессия Claude Code на этом Mac работает как помощник. Чтобы временно работать без него: `claude plugin disable assistant@upsideflow`; вернуть — `claude plugin enable assistant@upsideflow`.
- Бот молчит — проверьте, что Claude Code запущен командой из «Каждый день», окно открыто и Mac не уснул.
- Почта или календарь «не подключены» — подключите на https://claude.ai/customize/connectors и перезапустите Claude Code.
- CRM ответила «Запись через это подключение выключена» — в Claude Code `/mcp` → upsideflow-crm: выйдите и войдите снова, на экране согласия поставьте галочку «Разрешить запись в CRM через это подключение».
